# Update README

Before launching the readme-manager, do the following quickly:

1. Note the key changes that were made (e.g. new features, bug fixes, config changes) — you already know this from the work just completed

Then launch the readme-manager with this task, including the summary:
"Update the existing README. Here is a summary of what changed: <add summary here>. Context or focus area from user (if any): $ARGUMENTS"

Do not spend time deeply researching the changes — the readme-manager will handle that.
The agent will review the current README and update only the sections that need changes.
